# 프로필

## 12. 프로필

### 12.1 프로필 열람

- 사용자는 자신의 프로필과 다른 승인 사용자의 프로필을 열람한다.
- 프로필의 정식 URL은 고유 공개 ID를 쓰는 `/profile/:pubId`이며, `/profile`은 현재 로그인한 사용자의 프로필로 이동하는 편의 경로다.
- 공개 ID는 영문 소문자, 숫자, 하이픈으로 구성된 5자 이상 15자 이하의 문자열이며 대소문자를 구분하지 않고 고유하다.
- 혼동을 일으킬 수 있는 `admin`, `administrator`, `teacher`, `staff`, `moderator`, `support`, `system`, `root`, `sibal`은 공개 ID로 사용할 수 없다.
- 게시물 작성자, 댓글 작성자, 그룹 멤버에서 프로필로 이동할 수 있다.

프로필에는 다음 정보를 표시한다.

- 프로필 사진과 커버 사진
- 이름과 앱 관리자 배지
- 기수, 계열, 교사 표시. 복학생의 기수는 `n.5기`로 표시한다
- 학번, 반, 부서, 기숙사 방, 성별, 생일, 전화번호, 연락용 이메일 중 값이 있는 항목
- 소개
- 프로필 타임라인

표시 규칙은 다음과 같다.

- 정보 항목은 학적 정보, 연락처, 기타 정보로 묶어 표시한다. 값이 하나도 없는 묶음은 표시하지 않는다.
- 좁은 화면에서는 첫 묶음만 표시하고 더 보기와 접기로 나머지 묶음을 펼치거나 접는다. 넓은 화면에서는 모든 묶음을 표시한다.
- 소개는 처음에 두 줄까지 표시하며, 잘린 경우 더 보기와 접기로 전체 내용을 펼치거나 접을 수 있다.
- 다른 사용자의 등록된 프로필 사진이나 커버 사진을 선택하면 이미지 뷰어에서 원본을 연다. 기본 이미지와 비어 있는 커버는 열지 않는다.
- 전화번호와 연락용 이메일은 처음에 일부를 가려 표시한다. 전화번호는 마지막 네 자리 숫자를, 연락용 이메일은 로컬 파트 앞 두 글자와 도메인을 남긴다. 이는 프로필이 명부처럼 읽히지 않게 하는 표시 규칙이며 열람 권한을 제한하지 않는다.
- 가려진 전화번호나 연락용 이메일을 선택하면 전체 값을 표시하고, 표시된 값을 다시 선택하면 전화 연결 또는 메일 작성을 시작한다.
- 프로필 타임라인에서 해당 사용자를 대상으로 작성된 개인 게시물을 최신순으로 확인하며, 프로필 당사자는 자신의 비공개 게시물도 함께 본다.

### 12.2 프로필 편집

자신의 프로필 편집 화면은 `/profile/:pubId/edit`이며 프로필 당사자만 접근할 수 있다.

모든 사용자는 다음 항목을 편집한다.

- 공개 ID
- 이름
- 소개
- 생일
- 전화번호
- 연락용 이메일
- 타인의 내 타임라인 게시물 작성 허용 여부

재학생은 성별, 계열, 부서, 반, 기숙사 방과 재입학 여부를, 졸업생은 성별과 계열을 편집한다. 교사는 학적 정보를 사용하지 않는다.

생일, 전화번호, 성별, 계열은 선택 정보(§5.1)라 비워 저장할 수 있으며, 지우면 바로 삭제된다. 생일은 연·월·일을 모두 고르거나 모두 비워야 저장된다.

입력 제한은 다음과 같다.

- 이름은 1자 이상 50자 이하다.
- 소개는 최대 500자다.
- 전화번호는 앞자리 `+`를 허용하는 숫자, 공백, 하이픈 조합으로 8자 이상 20자 이하다.
- 연락용 이메일은 이메일 형식이어야 한다.
- 반은 1 이상 10 이하, 기숙사 방은 101 이상 1008 이하다.
- 공개 ID는 §12.1의 형식과 예약어 규칙을 따르며, 이미 쓰이는 값으로는 바꿀 수 없다.

공개 ID 변경은 다음과 같이 다룬다.

- 변경 횟수와 주기는 제한하지 않는다.
- 저장하면 프로필 주소가 곧바로 바뀌고, 이전 주소는 더 이상 본인의 프로필로 연결되지 않는다. 편집 화면은 저장 전에 이 사실과 이전 공개 ID를 다른 사용자가 다시 쓸 수 있다는 사실을 알린다.
- 놓아준 이전 공개 ID는 다른 사용자가 다시 쓸 수 있다.
- 편집 화면은 공개 ID를 맨 아래 프로필 주소 묶음에서 `공개 ID`라는 이름으로 편집하게 한다.

사용자는 기수, 학번, 사용자 유형, 계정 상태 및 앱 관리자 역할을 직접 변경할 수 없다.

편집 화면은 다음과 같이 동작한다.

- 저장 버튼은 바뀐 값이 있을 때만 활성화된다.
- 저장하지 않은 변경이 있는 채로 화면을 떠나면 나갈지 확인한다.

### 12.3 프로필 이미지 편집

- 자신의 프로필 사진과 커버 사진을 등록, 변경 및 자를 수 있다.
- 프로필 사진은 1:1, 커버 사진은 3:1 비율로 자르며, 이미지를 이동하고 확대·축소해 사용할 영역을 정한다.
- JPEG, PNG, WebP, HEIC, HEIF 입력을 지원하며 저장 전 WebP로 재인코딩해 메타데이터를 제거하고 용량을 제한한다.
- 프로필 사진이나 커버 사진을 등록 또는 변경하면 자신의 타임라인에 전체 공개 활동 게시물을 만든다. 활동 게시물에는 변경 당시 이미지 하나와 `이름님이 프로필 사진을 바꾸었습니다.` 또는 `이름님이 프로필 커버를 바꾸었습니다.` 문구를 표시한다.
- 프로필 사진은 작은 프로필 표시에 쓰는 512px 이미지와 변경 활동에서 크게 보는 2048px 이미지를 함께 만든다. 커버 사진은 기존 2400px 이미지를 변경 활동에도 사용한다.
- 기본 이미지로 되돌릴 때는 활동 게시물을 만들지 않는다.
- 자신의 등록된 프로필 사진이나 커버 사진은 이미지 편집 메뉴에서 이미지 뷰어로 열 수 있다.
- 이미지 편집은 프로필 화면과 프로필 편집 화면 양쪽에서 할 수 있으며, 프로필 편집의 저장과 상관없이 즉시 저장된다.

### 12.4 프로필 타임라인

- 승인 사용자는 자신의 타임라인과 다른 승인 사용자의 타임라인을 열람한다.
- 타임라인에는 해당 프로필을 대상으로 작성된 전체 공개 개인 게시물을 최신순으로 표시하고, 자신의 타임라인에서는 자신이 작성한 비공개 게시물도 함께 표시한다.
- 타임라인 당사자가 타인 작성을 허용하면 다른 승인 사용자가 해당 타임라인에 글을 작성할 수 있다. 허용하지 않은 타임라인에서는 글쓰기 진입점을 표시하지 않으며 설정값을 문구로 알리지 않는다.
- 타인 작성 허용을 꺼도 기존 타인 게시물은 유지하며 당사자가 개별적으로 삭제할 수 있다. 당사자는 타인이 작성한 글을 수정할 수 없다.
- 타임라인은 게시물을 카드로만 표시하며 카드·목록 보기 전환과 카테고리 필터를 두지 않는다.
- 타임라인 목록 하단에 도달하면 이전 게시물을 이어서 불러온다.
- 타임라인에서 게시물을 선택하면 그룹 게시물과 같은 모양의 게시물 상세를 연다.
- 프로필 미디어 변경 활동은 수정할 수 없지만 일반 개인 게시물과 같이 댓글, 반응, 공유 및 작성자 삭제를 지원한다.

### 12.5 콕 찌르기

승인 사용자가 다른 승인 사용자에게 가볍게 인사를 건네는 기능이다. 서로 되찌르며 앱에 다시 들어올 이유를 만든다.

- 다른 사람의 프로필에서 `콕 찌르기` 버튼으로 찌른다. 좁은 화면에서는 `메시지 보내기`와 폭을 반씩 나눠 왼쪽에 두고, 넓은 화면에서는 `메시지 보내기` 왼쪽에 둔다. 버튼은 보조(`secondary`) 배경이다. 자신의 프로필에는 두지 않는다.
- 찌를 수 있는 대상은 승인되어 이용 중인 사용자다. 자신, 탈퇴한 사용자, 승인 전이거나 이용 정지(§16.11) 중인 사용자는 찌를 수 없다.
- 찌르기는 두 사람이 번갈아 한다. 한 번 찌르면 상대가 되찌르거나 14일이 지나기 전까지 같은 사람을 다시 찌를 수 없고, 그동안 버튼은 `콕 찔렀어요`로 비활성화한다.
- 찔린 사람이 14일 동안 되찌르지 않으면 그 찌르기는 받은 콕 찌르기와 알림 인원(§14.14)에서 빠지고, 찔린 사람의 추천에 그 사람이 나온다. 찌른 사람은 다시 찌를 수 있다.
- 두 사람 사이에 주고받은 횟수를 센다. 이 횟수는 끊기지 않고 계속 늘어난다.
- 찌를 때마다 1% 확률로 `푹 찌르기`가 된다. 확률은 서버가 정하며 사용자가 고를 수 없다. 푹 찌르기도 번갈아 찌르기와 주고받은 횟수에서는 한 번으로 센다. 두 사람 사이의 푹 찌르기 횟수는 따로 센다.
- 푹 찌르기가 되면 특별한 효과를 1초 안팎으로 보여 준다. 찌른 사람은 찌른 직후에, 찔린 사람은 그 푹 찌르기를 콕 찌르기 화면에서 처음 볼 때 한 번 본다. 기기에서 동작 줄이기를 켠 사용자에게는 움직임 없이 잠깐 나타났다 사라진다.
- 콕 찌르기 기록은 계속 보관한다. 알림은 알림 보관 규칙(§14.1)을 따른다.

콕 찌르기 화면은 `/pokes`이며 메뉴(§15.1)와 콕 찌르기 알림(§14.14)에서 들어간다. 뒤로가기는 메뉴로 간다.

- 맨 위에서 이름으로 회원을 찾아 바로 찌를 수 있다.
- `받은 콕 찌르기`에는 내가 되찌를 차례이고 찔린 지 14일이 지나지 않은 사람을 최근 순서로 최대 100명 보여 준다. 행마다 프로필 사진, 이름, 찌른 시각, 주고받은 횟수(`N번째`), 푹 찌르기 횟수(`푹 N번`, 한 번 이상일 때)를 표시하고 `콕 찌르기`(되찌르기)를 둔다. 마지막이 푹 찌르기였으면 `푹` 배지를 붙인다. 찌른 사람이 탈퇴했거나 이용 정지 중이면 보여 주지 않는다. 받은 찌르기를 따로 숨기는 기능은 두지 않는다.
- `추천`에는 최대 5명을 보여 준다. 나를 찔렀지만 14일 동안 되찌르지 않은 사람을 기수와 상관없이 먼저 두고, 이어서 같은 기수의 회원을 둔다. 내가 찌르고 되찌르기를 기다리는 사람과 받은 콕 찌르기에 있는 사람은 빼며, 같은 묶음 안의 순서는 하루 동안 바뀌지 않는다. 기수가 없는 사용자에게는 같은 기수 추천을 두지 않는다.
- 내가 찌르고 답을 기다리는 사람의 목록은 두지 않는다. 특정 사람이나 콕 찌르기 전체를 받지 않는 설정은 제공하지 않는다.
- 화면을 열면 콕 찌르기 알림을 읽음 처리한다. 화면을 켜 둔 채 새로 찔려 목록이 바뀔 때도 읽음 처리하고, 그 찌르기가 푹 찌르기면 효과를 보여 준다.
